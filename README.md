# Student ID Card Generator

## Subject
Advanced Web Technology

## Subject Code
23UITPCL3508

---

## Overview
A web-based Student ID Card application that provides an interactive registration form with real-time validation and dynamic DOM manipulation.

## Features
- Student Registration Form: Interactive input fields for student details.
- Form & Field Validation: Ensures required fields are filled out correctly.
- Email Validation: Validates user email formats.
- Personalized Skill Level: Dynamically processes and displays user skill inputs.
- Array Iteration (`forEach`): Efficient processing of student data arrays.
- DOM Manipulation: Real-time rendering and updates of student information on the page.
